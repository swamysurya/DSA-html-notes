What is std::vector?

In C++, std::vector is a sequence container that represents a **dynamic array**. Unlike standard static arrays, vectors can resize themselves dynamically when elements are inserted or deleted, with all their elements stored in contiguous memory locations.

🔑 Contiguous Memory & Size vs. Capacity

Because vector elements are contiguous, we can access them in O(1) time using pointers/indices. To avoid allocating memory on every single insert, a vector separates its **Size** from its **Capacity**:

  • Size (N): The number of actual elements currently stored in the vector.
  • Capacity (C): The total amount of memory slots currently allocated.
  • Doubling Rule: When size reaches capacity (N == C) and a new item is pushed, the vector allocates a new block of size 2 × C, copies all old elements into the new block, and deletes the old block.

Amortized O(1) Insertion

Inserting at the end (`push_back`) is usually a simple write operation taking O(1) time. However, when a reallocation copy is triggered, the operation takes O(N) time.

Since doubling capacity happens less and less frequently as the vector grows, the average (amortized) time complexity for a sequence of push operations remains strictly O(1).

Step-by-Step Reallocation Trace

Page 2

Let us trace pushing values 10, 20, 30 into an empty vector initialized with **capacity = 2**.

Step 1: Push 10

Size = 1, Capacity = 2. Element written at index 0.

Step 2: Push 20

Size = 2, Capacity = 2. Element written at index 1. Capacity is now full.

Step 3: Push 30 (Reallocation Copy!)

• Since size equals capacity (2 == 2), the vector allocates a new memory block of size 4.
• Values 10 and 20 are copied to the new block. The old block is freed. 30 is written at index 2.
• Size = 3, Capacity = 4.

Vector Methods & Complexity Analysis

Page 3

Primary std::vector Operations

Method Description Average Time Worst-Case Time
push_back(val) Adds element to the end of the array. Amortized O(1) O(N) (realloc)
pop_back() Removes the last element. Capacity is not reduced. O(1) O(1)
operator[idx] Returns element at index. Direct memory access. O(1) O(1)
insert(pos, val) Inserts at pos. Shifts remaining elements to the right. O(N) O(N)
erase(pos) Removes element at pos. Shifts remaining elements left. O(N) O(N)

📝 Memory Overhead & Performance Trade-offs:

  • Fast Random Access: Direct address math Address = Start + Index * SizeOfElement allows O(1) reading.
  • Shifting Cost: Inserting or erasing in the middle is expensive because all elements to the right must be moved in memory.
  • Reserve Hint optimization: If the size of the elements is known, calling vector::reserve(n) pre-allocates enough capacity, eliminating reallocation copy overhead.
