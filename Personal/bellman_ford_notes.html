1. Bellman-Ford Fundamentals

Page 1

1. Single Source Shortest Path (SSSP)

The Single Source Shortest Path (SSSP) problem is defined as follows:

  • We are given a directed, weighted graph G = (V, E).
  • We choose one vertex as the designate source vertex S.
  • We want to determine the minimum cost (shortest path) from the source to every other vertex in the graph.
⚖️ Why Bellman-Ford over Dijkstra?

We already know Dijkstra's algorithm, which uses a greedy strategy. However, Dijkstra makes an irrevocable greedy choice assuming that once a node's shortest path is finalized, no further reduction is possible.

❌ Dijkstra does NOT guarantee correct results when the graph contains negative-weight edges!

✅ Bellman-Ford is specifically engineered to handle negative edge weights correctly and reliably.

2. Basic Idea of Bellman-Ford

Instead of greedily picking the nearest unvisited node, Bellman-Ford takes a dynamic programming / exhaustive relaxation approach:

Core Principle: Bellman-Ford repeatedly relaxes all edges in the graph.

If there are V vertices in the graph, we relax all edges:

V - 1 times
🤔 Why do we repeat (V - 1) times?

A shortest path without loops can have at most V - 1 edges.

In the worst case, every time you check all the edges once, the correct shortest distance spreads at least one edge further down the path.

💡 Example: If a graph has V = 7 vertices, the longest path has at most V - 1 = 6 edges. Therefore, checking all edges 6 times guarantees that the correct distance reaches all vertices from start to finish.

3. What is Relaxation?

Consider a directed edge: u → v with edge weight (cost) w.

At any point in time, we maintain the best known estimates:

  • distance[u]: Cost to reach u from source.
  • distance[v]: Current best cost to reach v from source.
📐 Relaxation Formula: 
if (distance[u] + weight(u, v) < distance[v]) {
    distance[v] = distance[u] + weight(u, v);
}
🗣️ In Simple English:
"Can I reach node v more cheaply by first travelling to node u and then taking the directed edge u → v?"

If yes, we discard the older higher cost and update distance[v] with this improved path cost.

Visualizing edge relaxation: distance[u] + weight(u,v) = 4 + 2 = 6 < ∞, so distance[v] drops to 6.

📋 The Algorithm in Plain English (How We Solve This 7-Node Graph) Plain English Steps
Step 1: Set Up Starting Distances

We start at Node 1, so set its distance to 0.
Since we don't know the cost to reach any of the other 6 nodes yet, set their distances to infinity (∞).

Step 2: Decide How Many Rounds to Run

Because there are 7 nodes, any path without loops has at most 6 edges (7 - 1 = 6).
So, we will repeat our checking process for at most 6 rounds.

Step 3: In Each Round, Check Every Edge One by One

Go through all 10 edges in the exact listed order. For each road from u → v, ask:

"Can I reach node v with a smaller cost by coming through node u?"

If yes (distance[u] + edge weight < distance[v]), erase the old distance at node v and write down the new smaller number!

Step 4: Check if Distances Stopped Changing (Early Finish)

If we finish a full round and no node's distance got smaller, the graph has completely stabilized. All shortest paths have already been found, so we can stop immediately! (In our 7-node example, this happens after Round 3).

Step 5: Final Result

The numbers written on all 7 nodes are now the guaranteed shortest path distances from Node 1.

10. Time Complexity Analysis

Bellman-Ford operates via two distinct structural loops:

  1. An outer loop that repeats exactly V - 1 times.
  2. An inner loop that examines all E edges during every single pass.
Standard Time Complexity: O(V · E)
Special Case: Complete Graph

In a complete directed graph where an edge exists between every pair of vertices:

E = V(V - 1) / 2 ≈ O(V²)

Substituting E = O(V²) into O(V · E) gives:

O(V · V²) = O(V³)

Graph Type Edges (E) Bellman-Ford Time Dijkstra (Heap)
General Sparse Graph O(V) O(V²) O(V log V)
General Dense Graph O(E) O(V · E) O(E log V)
Complete Graph O(V²) O(V³) O(V² log V)

4. Negative-Weight Cycles & Detection

Page 4

13. The Drawback — Negative-Weight Cycle

Now, let us modify the previous 4-vertex graph by adding a directed back-edge:

Add edge: 2 → 4 with weight = 5

This creates a directed cycle among vertices: 2 → 4 → 3 → 2.

Cycle Weight Calculation:
  • • 2 → 4 = 5
  • • 4 → 3 = 3
  • • 3 → 2 = -10
Total Cycle Weight = 5 + 3 + (-10) = 8 - 10 = -2 < 0
⚠️ Because total weight is negative, this is a Negative-Weight Cycle!
Negative Cycle: 2 → 4 → 3 → 2 loop has net cost -2 per traversal.

14. Why Is a Negative Cycle a Fatal Problem?

Every time an algorithm traverses around this cycle, the total path cost decreases by 2:

1st Loop -2
2nd Loop -4
3rd Loop -6
k-th Loop -∞
🛑 Fatal Consequence:

There is NO finite shortest path!

An agent or traveler can endlessly loop around the cycle to make the distance arbitrarily negative (-100, -1000, ... -∞). The optimization problem is unbounded and ill-defined for all reachable nodes downstream of the cycle.

15. How Bellman-Ford Detects a Negative Cycle

While no algorithm can find a finite shortest path in the presence of a reachable negative cycle, Bellman-Ford possesses a superpower: it can detect the cycle!

The Detection Procedure:

1. Relax all edges normally for V - 1 iterations.
2. Then, perform one additional (the V-th) iteration over all edges.

Case 1: No Distance Changes

Every edge satisfies d[u] + w ≥ d[v].
→ No reachable negative cycle exists.
Shortest distances are mathematically optimal and finalized!

Case 2: Any Distance Decreases

There exists at least one edge where d[u] + w < d[v].
→ Negative-weight cycle detected!
Report error: no finite shortest path exists.

Why does this test work?

A simple shortest path without cycles can have at most V - 1 edges. Thus, after V - 1 passes, every acyclic shortest path is fully relaxed. If a distance can still be reduced on the V-th pass, that reduction can only be caused by a path traversing more than V - 1 edges—meaning it repeated vertices (a cycle) whose sum is negative!

16. Negative Edge vs. Negative Cycle

Students and engineers frequently confuse these two concepts. Keep this crystal clear:

Graph Scenario Bellman-Ford Behavior Finite Shortest Path?
Positive edge weights only ✅ Works correctly Yes
Negative edge weights (no negative cycles) ✅ Works correctly Yes
Positive-weight cycle ✅ Works (cycle is simply avoided) Yes
Zero-weight cycle ✅ Works (cycle adds no benefit) Yes
Negative-weight cycle ⚠️ Detects & flags the cycle No (Path cost = -∞)
📌 Golden Rule: Negative Edge ≠ Negative Cycle

17. Bellman-Ford Algorithm Specification

Formal pseudocode specification for Bellman-Ford with cycle detection: 

Algorithm BellmanFord(Graph, Source):
    // Step 1: Initialization
    FOR each vertex v in Graph.V:
        distance[v] = ∞
    distance[Source] = 0

    // Step 2: Relax all edges |V| - 1 times
    FOR i from 1 to |Graph.V| - 1:
        FOR each edge (u, v, weight) in Graph.E:
            IF distance[u] + weight < distance[v]:
                distance[v] = distance[u] + weight

    // Step 3: Check for reachable negative-weight cycle
    FOR each edge (u, v, weight) in Graph.E:
        IF distance[u] + weight < distance[v]:
            RETURN "Error: Graph contains a reachable negative-weight cycle"

    // Step 4: Return valid shortest paths
    RETURN distance[]

19. Key Points to Remember (Revision Sheet)

Summary flashcard for fast exam revision and technical interview prep:

🎯 Problem & Mechanism
  • Solves the Single Source Shortest Path (SSSP) problem on directed, weighted graphs.
  • Unlike Dijkstra, Bellman-Ford safely accommodates negative-weight edges.
  • Executes by repeatedly performing edge relaxation: d[u] + w < d[v].
  • Edges must be relaxed V - 1 times, since a simple path has at most V - 1 edges.
⚡ Complexity & Cycles
  • General Graph Time Complexity: O(V · E).
  • Complete Graph Time Complexity: O(V³).
  • Space Complexity: O(V) for the distance array.
  • Can detect negative-weight cycles via a final 1-pass verification over all edges.
  • If any distance changes on the extra pass, an unbounded negative cycle exists!
