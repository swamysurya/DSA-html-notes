What is std::stack?

In C++, std::stack is a **container adapter**. It is not a standalone container; instead, it encapsulates an underlying sequence container (by default, std::deque, but can be configured to use std::vector or std::list) and exposes a strict **LIFO (Last In First Out)** interface.

🔑 LIFO Interface Restriction

A stack acts like a physical stack of plates. You can only interact with the top item:

  • Push: Inserts a new element at the very top of the stack.
  • Pop: Removes the top element.
  • Top: Accesses the value of the top element.
  • No direct iteration: You cannot read elements in the middle of the stack directly; you must pop elements on top of them first.

Container Adapter encapsulation

Because `std::stack` wraps sequence containers, it exposes only a subset of their APIs to restrict illegal access. For example:

  • `stack::push` delegates to `container::push_back`.
  • `stack::pop` delegates to `container::pop_back`.
  • `stack::top` delegates to `container::back`.
Conceptual Stack Cylinder: Elements are pushed and popped from the top of the cylinder.

Step-by-Step Stack Operations

Page 2

Let us trace pushing values **10, 20, 30** and then popping once.

Step 1: Empty State

Empty vertical stack container.

Step 2: Push 10

10 falls to the bottom of the stack. Top = 10.

Step 3: Push 20 & Push 30

20 is stacked on 10, then 30 is stacked on 20. Top = 30.

Step 4: Pop

The top element (30) is removed. The new top becomes 20.

Stack Methods & Complexity Analysis

Page 3

Primary std::stack Operations

Method Description Average Time Worst-Case Time
push(val) Adds element to the top of the stack. O(1) O(1)
pop() Removes the top element from the stack. O(1) O(1)
top() Returns reference to the top element. O(1) O(1)
size() / empty() Returns element count or checks if stack is empty. O(1) O(1)

📝 Adapter Efficiency:

  • All stack modifications take strictly **O(1)** time, making stacks highly efficient adapters.
  • Stacks are essential for tracking function calls, matching brackets, depth-first searches (DFS), and parsing expressions.
