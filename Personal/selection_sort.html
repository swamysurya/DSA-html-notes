What is Selection Sort?

**Selection Sort** splits the array conceptually into two segments: a **sorted prefix** at the left and an **unsorted suffix** at the right. It repeatedly scans the unsorted suffix to locate the minimum element, then swaps it with the first element of the unsorted suffix.

🔑 Core Attributes

  • Unstable Sort: Due to distant elements swapping, it can alter the relative order of duplicate elements.
  • Minimal Swaps: Selection sort executes at most **N swaps** total, making it highly efficient when memory writes are extremely expensive.
  • Constant Comparison load: Unlike bubble sort, selection sort always performs N × (N-1) / 2 comparisons, regardless of whether the input is already sorted.

Finding the Minimum

In each pass `i`, a pointer scans from `i + 1` to `N-1`. The index of the smallest element found (`min_idx`) is tracked. Once the loop ends, `arr[i]` and `arr[min_idx]` are swapped, growing the sorted prefix by 1 element.

Let us trace the first pass of selection sorting the array: `[5, 3, 4, 1]`.

Step 1: Locate Minimum (Index 0 to 3)

• Initial minimum: `arr[0] = 5`. Pointers scan right.
• Scanning indices finds `1` at index 3 is smaller than 5. Set `min_idx = 3`.

Step 2: Swap minimum into index 0

Swap `arr[0]` (5) and `arr[3]` (1). Array becomes `[1, 3, 4, 5]`. (1 is now sorted).

Selection Sort Complexity Analysis

Page 3

Asymptotic Runtime Bounds

Case Scenario Time Complexity
Best Case Array is already sorted. However, inner loops must scan completely to verify, taking N*(N-1)/2 comparisons. O(N^2)
Average Case Elements are randomly distributed. Scan comparisons always equal O(N^2). O(N^2)
Worst Case Array is sorted in reverse order. Performs O(N^2) comparisons and N swaps. O(N^2)

📝 Space & Writes Advantage:

  • Auxiliary Space: In-place sorting, consuming only O(1) extra space.
  • Write Efficiency: Selection sort executes at most N swaps. Contrast this with bubble sort, which can perform up to O(N^2) swaps. This makes selection sort much faster if writing to memory is a performance bottleneck.
