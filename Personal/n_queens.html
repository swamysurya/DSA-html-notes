1. The 4-Queens Problem: Statement & Formulation

Chess rules, non-attacking constraints, and the 2 valid solutions

Tab 1 • Problem Formulation

📌 1. Problem Statement

The 4-Queens Problem is the classic challenge of placing 4 non-attacking queens on a standard 4 × 4 chessboard.

👑 The Core Constraint:
“No two queens may attack each other: they cannot share the same row, the same column, or the same diagonal.”

In chess, a Queen is the most lethal piece: she can move arbitrarily many squares vertically, horizontally, or along any diagonal. Therefore, placing 4 queens safely requires enforcing three strict rules simultaneously:

↔️ 1. Row Constraint

No two queens can be in the same row. By assigning exactly one queen per row (Row $i$ holds Queen $i$), this condition is satisfied automatically by design!

↕️ 2. Column Constraint

No two queens can share the same column. If Queen $i$ is at column $x[i]$ and Queen $j$ is at column $x[j]$, we must ensure:

x[i] ≠ x[j]   (for all i ≠ j)

↗️ 3. Diagonal Constraint

No two queens can share a major or minor diagonal. This translates to the absolute difference condition:

|i - j| ≠ |x[i] - x[j]|

🏆 2. The Two Distinct Solutions

For $N = 1$, the problem is trivial ($[1]$). For $N = 2$ and $N = 3$, it is mathematically proven that zero valid solutions exist. For $N = 4$, there exist exactly two symmetric solutions:

Solution 1: [2, 4, 1, 3] Valid
  • Row 1: Queen at Col 2 $(1, 2)$
  • Row 2: Queen at Col 4 $(2, 4)$
  • Row 3: Queen at Col 1 $(3, 1)$
  • Row 4: Queen at Col 3 $(4, 3)$
Solution 2: [3, 1, 4, 2] Valid (Mirror)
  • Row 1: Queen at Col 3 $(1, 3)$
  • Row 2: Queen at Col 1 $(2, 1)$
  • Row 3: Queen at Col 4 $(3, 4)$
  • Row 4: Queen at Col 2 $(4, 2)$

In a pure brute force search, placing 4 queens across 4 columns without pruning would generate $4^4 = 256$ leaf nodes. With backtracking, each node checks the bounding function: if placing a queen in Row $k$ clashes with any previously placed queen in Rows $1 \dots k-1$, the branch is pruned immediately.

3. Step-by-Step Backtracking Execution Trace

Detailed chronological trace laid out sequentially down the page with state diagrams

Tab 3 • Execution Trace

Let us trace the algorithm systematically starting with placing Queen 1 on Chair/Row 1. Notice how every dead-end triggers a retreat up the recursion stack!

Step 1: Place Queen 1 at (1, 1) Row 1 Placed

Action: Place Queen 1 at row 1, column 1 ➜ State: [1].

Bounding Check: No prior queens exist. Trivially valid! Proceed to Row 2.

Step 2: Try Row 2 Columns under Queen at (1, 1) Pruning & Advance
  • Try $(2, 1)$ ➜ Column clash with $(1, 1)$ ($x[2] == x[1]$) ➜ PRUNE ✕
  • Try $(2, 2)$ ➜ Diagonal clash ($|2-1| = |2-1| = 1$) ➜ PRUNE ✕
  • Try $(2, 3)$ ➜ Column $3 \ne 1$, Diagonal $|2-1| = 1 \ne |3-1| = 2$ ➜ VALID ✅

State advances to [1, 3]. Proceed to Row 3!

Step 3: Try Row 3 under [1, 3] ➜ Deadlock & Backtrack! The Backtrack Moment

We now attempt to seat Queen 3 on Row 3 with prior state [1, 3]:

  • Try $(3, 1)$ ➜ Column clash with $(1, 1)$ ➜ PRUNE ✕
  • Try $(3, 2)$ ➜ Diagonal clash with $(2, 3)$ ($|3-2|=1, |2-3|=1$) ➜ PRUNE ✕
  • Try $(3, 3)$ ➜ Column clash with $(2, 3)$ ➜ PRUNE ✕
  • Try $(3, 4)$ ➜ Diagonal clash with $(2, 3)$ ($|3-2|=1, |4-3|=1$) ➜ PRUNE ✕
↩️ ALL 4 columns fail for Row 3! We BACKTRACK to Row 2: remove Queen from $(2, 3)$ and try column 4!
Step 4: Explore [1, 4] ➜ [1, 4, 2] ➜ Backtrack to Root! Deep Prune

Under $(2, 4)$, only $(3, 2)$ is valid for Row 3 ➜ State: [1, 4, 2].

For Row 4: cols 1, 2, 3, 4 are completely attacked by the first 3 queens! Row 4 fails. Row 3 has no more cols. Row 2 has no more cols.

↩️ We backtrack all the way back to the Root! No solution exists with Queen 1 at Col 1.

Step 5: Queen 1 at (1, 2) ➜ Solution 1 Found! [2, 4, 1, 3] 🏆 Solution 1

Now start branch Row 1 = Col 2:

  • Row 2: Queen at Col 4 $(2, 4)$ is valid ✅
  • Row 3: Queen at Col 1 $(3, 1)$ is valid ✅
  • Row 4: Queen at Col 3 $(4, 3)$ is valid ✅

🎉 Depth 4 reached with all constraints satisfied: Solution 1 = [2, 4, 1, 3] recorded!

Step 6: Queen 1 at (1, 3) ➜ Solution 2 Found! [3, 1, 4, 2] 🏆 Solution 2 (Mirror)

Following the same backtracking sequence for Row 1 = Col 3:

  • Row 2: Queen at Col 1 $(2, 1)$ is valid ✅
  • Row 3: Queen at Col 4 $(3, 4)$ is valid ✅
  • Row 4: Queen at Col 2 $(4, 2)$ is valid ✅

🎉 Solution 2 = [3, 1, 4, 2] recorded! Search terminates after exploring Col 4.

4. Bounding Function, Recursive Algorithm & Complexity

Formal Place(k, i) bounding predicate, canonical recursive backtracking implementation, and asymptotic bounds

Tab 4 • Code & Analysis

🛡️ 1. The Bounding Function: Place(k, i)

Before placing Queen $k$ at Column $i$, we test whether any already-placed queen in rows $j = 1 \dots k-1$ attacks it: 

function Place(k, i):
    // Returns true if queen can be placed in row k, column i
    for j = 1 to k - 1:
        // Check 1: Same column clash
        if x[j] == i:
            return false

        // Check 2: Same diagonal clash
        if abs(x[j] - i) == abs(j - k):
            return false

    return true  // Safe square!
💡 Time Complexity of Place(k, i):
$O(k)$ time — scans only the preceding $k-1$ rows, taking at most $O(N)$ operations per check.

🧩 2. Recursive Backtracking N-Queens Algorithm

The complete algorithm starts with NQueens(1, n): 

function NQueens(k, n):
    // k = current row to place queen on
    // n = board dimension (e.g. 4)

    for i = 1 to n:
        if Place(k, i):
            x[k] = i  // Choose column i for queen in row k

📊 3. Asymptotic Complexity Analysis

Approach Leaf States Generated Time Complexity Space Complexity
Pure Brute Force $N^N$ ($4^4 = 256$) $O(N^N)$ $O(N)$
Permutation Search $N!$ ($4! = 24$) $O(N!)$ $O(N)$
Backtracking with Pruning Only 2 solutions reached Upper bound $O(N!)$, far less in practice $O(N)$

Key Observations:

  • Space Efficiency: Only needs a 1D array of size $N$ (`x[1..n]`) and recursion stack depth $N$. Thus Space Complexity is strictly $O(N)$.
  • Pruning Power: For $N=4$, instead of generating 256 leaves, backtracking visits only a handful of nodes and cuts off entire swathes of dead branches on row 2 and row 3.
