What is Bubble Sort?

**Bubble Sort** is a basic comparison-based sorting algorithm. It works by repeatedly stepping through the list, comparing adjacent elements, and swapping them if they are in the wrong order. This process repeats until no swaps are needed, meaning the list is sorted.

🔑 Key Attributes

  • Stable Sort: Retains relative order of duplicate elements since elements are only swapped when one is strictly greater than the other.
  • Sinking Bubbles: In each pass, the largest unsorted element "bubbles up" or sinks to its correct position at the end of the array.
  • Optimized Check flag: If a complete pass finishes without triggering a single swap, the array is already sorted, and we can terminate early.

Pass Bounds Reduction

After pass `k`, the last `k` elements are guaranteed to be in their final sorted positions. Thus, the inner loop comparison boundary can contract to `N - k - 1`, avoiding redundant comparisons on already sorted tails.

Pass 1 Boundary Lock: Rightmost cell is locked at the end of pass 1.

Let us trace the first pass of bubble sorting the array: `[5, 1, 4, 2]`.

Step 1: Compare index 0 and 1

Comparison: `5 > 1`. Swap them. Array becomes `[1, 5, 4, 2]`.

Step 2: Compare index 1 and 2

Comparison: `5 > 4`. Swap them. Array becomes `[1, 4, 5, 2]`.

Step 3: Compare index 2 and 3

Comparison: `5 > 2`. Swap them. Array becomes `[1, 4, 2, 5]`. (5 is now locked in place).

Bubble Sort Complexity Analysis

Page 3

Asymptotic Runtime Bounds

Case Scenario Time Complexity
Best Case Array is already sorted. Requires 1 pass of N-1 comparisons (no swaps, triggers early exit). O(N) (Optimized flag)
Average Case Elements are randomly distributed. Requires about N^2 / 4 swaps and comparisons. O(N^2)
Worst Case Array is sorted in reverse order. Every adjacent check triggers a swap. O(N^2)

📝 Space Complexity & Stability:

  • Space: Requires only constant auxiliary variables for temp values during swap: O(1).
  • Stability: Yes. It is stable.
