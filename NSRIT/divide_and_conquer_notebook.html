Divide & Conquer Method & AVL Trees

Page 1

General Method Concept:

Divide and Conquer is a fundamental algorithm design paradigm. It works by:

  • Divide: The main problem is broken down into smaller, similar sub-problems.
  • Conquer: The sub-problems are solved recursively. If they are small enough, they are solved directly (base case).
  • Combine: The solutions of all sub-problems are merged back together to formulate the final answer.

Algorithm Structure:

DAC(p) {
    if (small(p)) {
        return S(p); // Solve directly
    } else {
        divide p into p1, p2, ..., pn
        Apply DAC(p1), DAC(p2), ...
        return Combine(DAC(p1), DAC(p2), ...)
    }
}

Merge Sort Sort & Division Tree

Page 2

Merge sort is a recursive algorithm that repeatedly divides a list in half until individual elements are isolated, then merges them back in sorted order.

MergeSort Algorithm:

Algorithm MergeSort(l, h) {
    if (l < h) {
        mid = (l + h) / 2;
        MergeSort(l, mid);
        MergeSort(mid + 1, h);
        Merge(l, mid, h);
    }
}

Merge Algorithm:

Algorithm Merge(l, mid, h) {
    i = l; j = mid + 1; k = l;
    while (i <= mid && j <= h) {
        if (A[i] <= A[j]) {
            B[k++] = A[i++];
        } else {
            B[k++] = A[j++];
        }
    }
    for (; i <= mid; i++) B[k++] = A[i];
    for (; j <= h; j++) B[k++] = A[j];
    for (i = l; i <= h; i++) A[i] = B[i];
}

Quick Sort & Partitioning Simulator

Page 3

Quick Sort operates by selecting a pivot element and partitioning the array so that elements smaller than the pivot go to the left, and elements larger go to the right.

Quick Sort Algorithm:

QuickSort(A, i, j) {
    if (i < j) {
        p = Partition(A, i, j);
        QuickSort(A, i, p - 1);
        QuickSort(A, p + 1, j);
    }
}

Partition Logic:

Partition(A, l, h) {
    pivot = A[l];
    i = l; j = h;
    while (i < j) {
        while (A[i] <= pivot && i < h) i++;
        while (A[j] > pivot) j--;
        if (i < j) swap(A[i], A[j]);
    }
    swap(A[l], A[j]);
    return j;
}

How Partition Positions the Pivot:

Partitioning works by selecting a pivot element and rearranging the other elements so that all values smaller than the pivot go to its left, and all values larger go to its right. Click the step button below to see how pivot 50 positions itself in its final sorted location.

💡 Why does this work? (Key Intuition)
  • Pointers i and j partition the elements: everything left of j gets swapped to be ≤ pivot, and everything right of i gets swapped to be > pivot.
  • When pointers cross (i ≥ j), index j marks the boundary of the left group. Since A[j] ≤ pivot, swapping the pivot with A[j] places the pivot exactly on this boundary.
  • After the swap, the pivot at index j has only smaller elements on its left and larger elements on its right. Thus, the pivot reaches its exact final sorted position.

Standard Algorithm / Pseudo Code (O(N³)):

MatrixMultiply(A, B, C, n) {
    for i = 0 to n - 1 {
        for j = 0 to n - 1 {
            C[i][j] = 0
            for k = 0 to n - 1 {
                C[i][j] = C[i][j] + A[i][k] * B[k][j]

Time Complexity: O(N³) due to the three nested loops, each iterating N times.
Space Complexity: O(1) auxiliary space.

To multiply matrices of a larger size N × N, we recursively divide them into four sub-matrices of size N/2 × N/2.

The smallest breakdown case where actual computation begins is a 2 × 2 matrix. This is because a 2 × 2 division yields exactly 4 quadrant block formulas: C₁₁, C₁₂, C₂₁, and C₂₂. These 4 equations represent the fundamental step where sub-problem solutions are merged back to construct the parent matrix.

Convex Hull - Divide & Conquer

Page 5
1. What is a Convex Hull?

Definition: It is the smallest outer boundary (a polygon in 2D or polyhedron in 3D) that completely encloses a given group of points. Think of it as stretching a rubber band around all the points; when released, the band forms the convex hull.

2. The Divide & Conquer Approach

Instead of solving the whole group of points at once, we break it down:

  • Divide: Split points by X-coordinate into left and right halves. Keep splitting recursively.
  • Base Case: Solve tiny groups directly using a simple method (brute-force approach with O(N³) complexity for groups of ≤ 5 points).
  • Conquer (Merge): Combine left hull (Shape A) and right hull (Shape B) into a single boundary.
3. How Merging Works

To combine two separate boundaries into one complete convex hull:

  • Draw the upper tangent line connecting the top of Shape A to the top of Shape B.
  • Draw the lower tangent line connecting the bottom of Shape A to the bottom of Shape B.
  • Remove the internal, facing lines and keep the outermost boundary.

Detailed Step-by-Step Merging Process

The merging phase is the core of the Divide and Conquer Convex Hull algorithm. Here is a detailed, step-by-step trace of how points are divided, local hulls are solved, and tangents are walk-searched in clockwise and counter-clockwise directions to merge them.

We start with a set of unsorted 2D points on the plane. To break the problem down, we sort all points by their X-coordinates and draw a vertical dividing line down the middle.

  • Left Half: Contains points A₁, A₂, and A₃.
  • Right Half: Contains points B₁, B₂, and B₃.
  • The red dashed vertical line represents the division boundary that separates the two subsets.

  • Since all other points in both hulls lie above this line, it forms the bottommost boundary.

Step 4: Merge Boundaries & Discard Internal Edges

We stitch the final unified boundary polygon using the upper and lower tangents and the outermost parts of both hulls, and discard the inner facing lines.

  • We walk the outermost path: A₁ → B₁ → B₂ → B₃ → A₃ → A₂ → close.
  • The internal lines A₁-A₃ and B₁-B₃ are discarded since they are now inside the enclosing shape.
  • This yields the final enclosing convex hull boundary.
