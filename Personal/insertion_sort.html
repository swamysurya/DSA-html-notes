What is Insertion Sort?

**Insertion Sort** mimics the way you sort playing cards in your hands. It splits the list into sorted and unsorted segments. It picks the first element of the unsorted segment (called the **key**) and inserts it into its correct position within the sorted segment by shifting larger elements one position to the right.

🔑 Core Attributes

  • Stable Sort: Safe duplicate handling since elements are only shifted if they are strictly greater than the key.
  • Adaptive Algorithm: Runs in O(N) linear time if the array is already sorted, making it ideal for nearly-sorted datasets.
  • In-place: Space complexity is O(1) constant.

Shifting Mechanics

Unlike selection or bubble sort, insertion sort does not perform swaps. Instead, it extracts the key value, creating a temporary hole, and shifts elements rightwards to make space. This significantly reduces write access overhead.

Prefix Shifting Concept: Elements shift to the right to insert key.

Step-by-Step Card Sort

Page 2

Let us trace insertion sorting the array: `[4, 3, 1, 2]`.

Step 1: Insert 3 (index 1)

• Key = `3`. Compare with sorted element `4`.
• Since `4 > 3`, shift `4` right and insert `3` at index 0. Array: `[3, 4, 1, 2]`.

Step 2: Insert 1 (index 2)

• Key = `1`. Compare with `4` and `3`.
• Shift `4` and `3` right, insert `1` at index 0. Array: `[1, 3, 4, 2]`.

Insertion Sort Complexity Analysis

Page 3

Asymptotic Complexity Metrics

Case Scenario Time Complexity
Best Case Array is already sorted. Each key is compared once and requires zero shifts. O(N) (Adaptive linear)
Average Case Keys are compared with half the sorted prefix elements on average. O(N^2)
Worst Case Array is sorted in reverse order. Every insert shifts all elements in the sorted prefix. O(N^2)

📝 Practical Strengths:

Insertion sort outperforms Merge and Quick Sort on **small array sizes** (usually N < 15) due to low constant overhead. Because of this, it is commonly used as the base case optimization in hybrid sorting algorithms like Timsort.
