What is std::queue?

In C++, std::queue is a **container adapter** designed to operate in a **FIFO (First In First Out)** context. Elements are inserted at the back and removed from the front.

🔑 FIFO Interface Restriction

A queue acts like a checkout line in a store. The first person to join the line is the first one served:

  • Push (Enqueue): Adds a new element at the **back** (tail) of the queue.
  • Pop (Dequeue): Removes the element at the **front** (head) of the queue.
  • Front: Accesses the value of the front-most element.
  • Back: Accesses the value of the back-most element.
  • No random access: Direct indexing (`queue[i]`) is disabled to guarantee queue behavior.

Underlying Container

Similar to stacks, `std::queue` wraps an underlying container (default std::deque, but can also wrap std::list).

  • `queue::push` delegates to `container::push_back`.
  • `queue::pop` delegates to `container::pop_front`.
Conceptual Horizontal Queue: Elements enter from the right (back) and leave from the left (front).

Step-by-Step Queue Operations

Page 2

Let us trace pushing values **10, 20, 30** and then popping once.

Step 1: Empty Queue

Empty horizontal queue tube.

Step 2: Push 10 (Front = 10, Back = 10)

10 enters from the right and moves to the front.

Step 3: Push 20 & Push 30

20 enters from the right behind 10, followed by 30. Front = 10, Back = 30.

Step 4: Pop (Front is removed)

The front element (10) exits from the left. 20 slides to the front. New Front = 20, Back = 30.

Queue Methods & Complexity Analysis

Page 3

Primary std::queue Operations

Method Description Average Time Worst-Case Time
push(val) Enqueues element at the back of the queue. O(1) O(1)
pop() Dequeues element from the front of the queue. O(1) O(1)
front() / back() Accesses value of front-most or back-most element. O(1) O(1)
size() / empty() Returns element count or checks if queue is empty. O(1) O(1)

📝 Queue Usage Contexts:

  • All modifications run in strictly **O(1)** time.
  • Queues are essential for Breadth-First Searches (BFS) on graphs, buffer management (FIFO pools), spooling logs, and task schedulers.
