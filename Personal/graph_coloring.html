1. Graph Coloring (m-Coloring Problem)

Sample 4-cycle graph $C_4$, colors {Red, Green, Blue}, discovering valid configurations, and why Backtracking is chosen

Exam Standard • Unit 7
📝 Core Observation: "Unlike Greedy algorithms which only output a single approximate answer, or Dynamic Programming which is meant for optimization problems, Backtracking is designed to systematically find ALL valid configurations (multiple solutions)! When an assignment violates the adjacency rule, we immediately prune the branch and backtrack to find alternative valid colorings!"
📋

1.1 Problem Statement

Given an undirected graph G = (V, E) with n = 4 vertices and a set of m = 3 available colors: Red (1), Green (2), and Blue (3).

🎯 The Goal (m-Coloring Problem):

Assign one color x[i] ∈ {1, 2, ..., m} to each vertex $i \in V$.

⚖️ Fundamental Adjacency Constraint:

∀ (u, v) ∈ E  ⟹  x[u] ≠ x[v]

No two adjacent (connected) vertices may be assigned the exact same color!

📐

1.2 Given Sample Graph (4-Cycle C₄) & Valid Answers

Vertices: n = 4 Colors: m = 3 Total Solutions = 18
Solution 1 (Uses 3 Colors): v₁=Red, v₂=Green, v₃=Blue, v₄=Green

💡 Why We Use Backtracking: Multiple Solutions Discovery

Notice that X = (Red, Green, Blue, Green) is one valid answer that utilizes all 3 given colors! In graph coloring, our goal is not just to find a single arbitrary answer, but to systematically discover all possible ways we can color the network.

⚠️ 3 Colors Given vs 2 Colors Minimum:

The problem gave us 3 available colors: {Red, Green, Blue}.

  • Solutions using all 3 colors (12 solutions): e.g., (R, G, B, G), (R, G, R, B), (R, B, G, B).
  • Solutions using only 2 colors (6 solutions): e.g., (R, G, R, G), (R, B, R, B), (G, B, G, B). These are also valid because the minimum chromatic number is $\chi(C_4) = 2$.
✨ Chromatic Polynomial Formula:

P(C₄, m) = (m - 1)⁴ + (m - 1) = (3 - 1)⁴ + (3 - 1) = 2⁴ + 2 = 18 Total Valid Solutions!

👉 Concluding Key Idea: Backtracking is nothing but systematic tree traversal to find MULTIPLE SOLUTIONS. We prune invalid paths and backtrack to explore every valid color configuration!

2. State-Space Trees: Brute Force vs Bounding Condition

Comparing the unconstrained ternary tree (Time Complexity: $O(m^n)$) against the pruned state-space tree

Tree Analysis
🌲

2.1 State-Space Tree WITHOUT Bounding Condition (Brute Force)

Time Complexity: O(mⁿ) = 3⁴ = 81 Leaves

If we ignore the adjacency constraint during generation, every vertex $i \in \{1, 2, 3, 4\}$ can independently take any of the m = 3 colors (Red, Green, Blue). This generates a complete ternary tree:

Level 0 (Root) 1 node 3⁰
Level 1 (Vertex 1) 3 nodes 3¹
Level 2 (Vertex 2) 9 nodes 3²
Level 3 (Vertex 3) 27 nodes 3³
Level 4 (Leaves) 81 leaves 3⁴ = 81
⚠️ Total Nodes Generated in Brute Force:
Total Nodes = 1 + 3 + 9 + 27 + 81 = 121 Nodes!

Time Complexity: O(mⁿ). Out of the 81 total leaf configurations generated by Brute Force, only 18 are valid, and 63 are completely invalid! Generating and testing every state is wildly wasteful.

✂️

2.2 State-Space Tree WITH Bounding Condition (Backtracking)

Adjacency Rule Imposed

Now impose the Bounding Function `isSafe(k, c)`. At Level $k$, before assigning color $c$ to vertex $k$, we check if any adjacent vertex already assigned has color $c$. If yes, the node is KILLED (Pruned ❌), and we never explore its children!

Vertex 4 is adjacent to both 3 and 1!
If 3 is Red and 1 is Red:

• $x_4 = G$ or $B$: VALID SOLUTIONS! 🏆

3. Map Coloring & The Four-Color Theorem

Real-world cartography, conversion to planar dual graphs, and how Backtracking solves map coloring

Applications
🗺️

3.1 What is the Map Coloring Problem?

In cartography (map making), cartographers need to color geopolitical maps (countries, states, provinces) such that no two adjacent countries sharing a common boundary border receive the same color. (Sharing only a single corner point does not count as adjacent).

🔄 How a Map is Converted into a Graph (Planar Dual)

  • Regions ➜ Vertices: Place a vertex inside each country / region.
  • Shared Borders ➜ Edges: Draw an edge between two vertices if their corresponding regions share a common land border line.
  • The resulting graph is a Planar Graph (can be drawn on a 2D plane without any edges crossing over each other).

🌍 The Famous Four-Color Theorem (1976)

Formulated in 1852 by Francis Guthrie and famously proven in 1976 by Kenneth Appel and Wolfgang Haken (the first major computer-assisted mathematical proof):

Every planar map can be colored using AT MOST 4 COLORS!

Chromatic number $\chi(G) \le 4$ for any planar graph without edge crossings.

🗺️ ➔ 🕸️

3.2 Visual Construction: How a Map Becomes a Planar Dual Graph

↔️ Side-by-Side: Left is the realistic map with curly irregular borders & alphabet regions (A, B, C, D, E); Right is the extracted Planar Dual Graph.
1. Territory ➔ Vertex:

Each bounded territory/country ($A, B, C, D, E$) becomes an independent vertex. Place a node inside the center of each territory.

2. Shared Border ➔ Dual Edge:

Whenever two countries share a border line of non-zero length, draw an edge across that border connecting their vertices. (Points touching at corners do NOT form edges).

3. Four-Color Theorem in Action:

Since the resulting dual graph is strictly planar (drawn without overlapping edges), Kenneth Appel & Wolfgang Haken's theorem guarantees it can always be colored using $\le 4$ colors!

⚙️

3.3 How Backtracking Solves Map Coloring Step-by-Step

1
Graph Representation:

Represent the map's $n$ countries as an $n \times n$ binary adjacency matrix graph[i][j] = 1 if country $i$ borders country $j$.

2
Sequential Assignment (DFS):

Start with Country 1. Try assigning Color 1 (e.g. Red). Move to Country 2, try Color 1, if it borders Country 1, reject and try Color 2 (Green).

3
Adjacency Bounding Check:

Before officially setting country $k$'s color, iterate over all already-colored neighbors: for (j = 1 to k-1) if (graph[k][j] && color[j] == c) return false;.

4
Backtracking on Conflict:

If all $m = 4$ colors conflict with existing neighbors of country $k$, we backtrack to country $(k - 1)$, change its color to the next untried color, and resume forward progress!

🚀 Other Real-World Engineering Uses of Graph Coloring

📱 Mobile Cell Tower Frequencies:

Adjacent cell towers cannot transmit on the same electromagnetic frequency channel to avoid signal interference.

📅 Exam & Flight Scheduling:

Courses with common enrolled students share an edge. Colors represent exam time slots so no student has overlapping exams.

⚙️ Compiler Register Allocation:

Variables with overlapping lifespans cannot occupy the same CPU hardware register (Chaitin's graph coloring algorithm).

4. Recursive Algorithm & Complexity Analysis

Canonical Horowitz & Sahni m-Coloring Backtracking procedure and asymptotic analysis

Code & Proof
💻

4.1 Canonical Backtracking m-Coloring Algorithm

C++ Implementation 
#include <iostream>
using namespace std;

const int MAX_V = 10;
int n = 4;                          // Number of vertices
int m = 3;                          // Number of colors
int graph[MAX_V][MAX_V];            // Adjacency matrix
int x[MAX_V];                       // Solution vector: x[k] is color of vertex k

// Bounding Function: Check if assigning color c to vertex k is safe
bool isSafe(int k, int c) {
    for (int i = 1; i <= n; i++) {
        // If there is an edge and adjacent vertex already has color c
        if (graph[k][i] == 1 && x[i] == c) {
            return false;  // Conflict: PRUNE!
        }
    }
    return true;           // Safe to color
}

// Backtracking procedure to find ALL valid colorings
void mColoring(int k) {
    // Try all colors from 1 to m for vertex k
    for (int c = 1; c <= m; c++) {
        // Check bounding condition
        if (isSafe(k, c)) {
            x[k] = c;  // Assign color

            // If all vertices colored, we found a valid solution!
            if (k == n) {
                cout << "Solution: ";
                for (int i = 1; i <= n; i++) cout << x[i] << " ";
                cout << "\n";
            } else {
                mColoring(k + 1);  // Explore next vertex
            }

            // Backtrack: Reset assignment
            x[k] = 0;
        }
    }
}
⏱️

4.2 Asymptotic Complexity Analysis

⏳ Time Complexity

• Worst-case Time: O(mⁿ).
In the worst case (e.g. an empty graph with no edges), all $m^n$ configurations are explored. At each node, `isSafe()` takes $O(n)$ time to check adjacent vertices, leading to $O(n \cdot m^n)$.

• Average-case Time: Drastically reduced! The bounding function prunes large sub-trees as soon as a color collision occurs at an early depth.

💾 Space Complexity

• Auxiliary Space: O(n).
The DFS recursion stack only grows to depth $n$ (one frame per vertex). The solution array `x[]` requires $O(n)$ space.

• The graph adjacency matrix takes $O(n^2)$ space (or $O(V + E)$ using adjacency lists).
