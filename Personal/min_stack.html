Min Stack Design & Principles

Constant Time $O(1)$ Minimum Retrieval in a LIFO Stack Data Structure

Page 1 • Foundations

📌 1. The Min Stack Problem

A standard stack operates under a strict Last-In, First-Out (LIFO) policy. We can easily perform:

  • push(val): Inserts element onto the top of the stack in O(1) time.
  • pop(): Removes the element from the top of the stack in O(1) time.
  • top(): Inspects the top element in O(1) time.

⚠️ The Problem with getMin() in Standard Stacks

Suppose we also want a function getMin() that retrieves the smallest value currently present in the entire stack.

  • Naive Approach: Iterate over all $N$ stack elements to find the smallest. Cost: $O(N)$ time per query!
  • Sorting Approach: If we sort elements to find the minimum instantly at the end, we destroy the LIFO order required for stack operations!
  • Single Variable Trap: If we merely store a variable int minVal, what happens when the current minimum element is pop()'d? We have no way of knowing what the previous minimum was without traversing!

💡 2. Architectural Approaches

Approach 1: Two Stacks / Pair Stack

O(N) Auxiliary Space

Maintain two synchronized stacks:

  1. Main Stack (st): Holds all actual elements in order of insertion.
  2. Auxiliary Min Stack (minSt): Holds the running minimum corresponding to each height of the main stack.

Push(x): Push $x$ to st. For minSt, push $\min(x, \text{minSt.top()})$.

Pop(): Pop top element from both st and minSt simultaneously.

getMin(): Directly return minSt.top() in $O(1)$!

*Variation: Optimized minSt only pushes when $x \le \text{minSt.top()}$, and pops from minSt only when popped value $== \text{minSt.top()}$.

Approach 2: O(1) Space (Math Trick)

O(1) Auxiliary Space

Store only one single stack and one variable minEle:

  1. When pushing $x \ge \text{minEle}$: Push $x$ normally.
  2. When pushing $x < \text{minEle}$: Encode the previous minimum into a flag value:
    encoded = 2x - minEle
    Push encoded to stack, then update minEle = x!

Pop(): Let $y = \text{stack.top()}$. If $y < \text{minEle}$, it is an encoded sentinel! The popped minimum is minEle. Restore previous minimum: prevMin = 2·minEle - y.

getMin(): Return minEle directly in $O(1)$!

📐 3. Mathematical Derivation: Why Does $2x - \text{min}$ Work?

How can we store a new element $x$ AND remember the old minimum $\text{min}_{\text{old}}$ using only a single slot?

Theorem 1: The Encoded Value is Strictly Smaller than $x$

When $x < \text{min}_{\text{old}}$, the difference $(x - \text{min}_{\text{old}}) < 0$ is strictly negative.

encoded = 2x - minold = x + (x - minold) < x

Since $x$ becomes the new minEle, we guarantee: encoded < minEle. This gives us a foolproof signal flag! Whenever the value on top of the stack is strictly less than minEle, we know with 100% mathematical certainty that this slot represents a minimum update!

Theorem 2: Perfect Reconstruction of Previous Minimum on Pop

When popping an encoded flag $y$:

y = 2x - minold    [where x = current minEle]
minold = 2·minEle - y

We extract the true minimum element (minEle) to return to the user, and instantaneously restore the previous minimum via simple arithmetic without any extra stack!

🚨 Interview Trap: 32-bit Signed Integer Overflow

In C++ or Java, standard int is 32-bit signed with values ranging from $-2^{31}$ to $2^{31}-1$ (approx $-2.14 \times 10^9$ to $+2.14 \times 10^9$).

When evaluating the formula 2·x - minEle, if $x$ is a very large negative number (e.g. $-2 \cdot 10^9$) and $\text{minEle} = 2 \cdot 10^9$, then:
2·(-2·10^9) - 2·10^9 = -6·10^9 < INT_MIN → Underflows!

🛡️ Remediation: Always use 64-bit integer types (long long in C++, long in Java) for the internal stack and minEle variable.

// APPROACH 2: Optimal O(1) Auxiliary Space with 2*x - minEle Encoding
// LeetCode 155 Min Stack
// =========================================================================
#include <stack>
#include <stdexcept>

class MinStack {
private:
    // Using long long to prevent 32-bit integer arithmetic overflow
    std::stack<long long> st;
    long long minEle;

public:
    MinStack() : minEle(0) {}

    void push(int val) {
        long long x = val;
        if (st.empty()) {
            minEle = x;
            st.push(x);
        } else if (x >= minEle) {
            // Element is not smaller than current minimum
            st.push(x);
        } else {
            // New minimum discovered! Store encoded flag: 2*x - minEle
            long long encoded = 2 * x - minEle;
            st.push(encoded);
            minEle = x;
        }
    }

    void pop() {
        if (st.empty()) return;
        
        long long y = st.top();
        st.pop();

        if (y < minEle) {
            // Encoded flag detected! Restore previous minimum
            minEle = 2 * minEle - y;
        }
    }

    int top() {
        if (st.empty()) throw std::runtime_error("Stack is empty");
        long long y = st.top();
        if (y < minEle) {
            // Top is an encoded marker; real element is minEle
            return (int)minEle;
        }
        return (int)y;
    }

    int getMin() {
        if (st.empty()) throw std::runtime_error("Stack is empty");
        return (int)minEle;
    }
};
import java.util.Stack;

class MinStack {
    private Stack<Long> stack;
    private Long minEle;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        long x = val;
        if (stack.isEmpty()) {
            minEle = x;
            stack.push(x);
        } else if (x >= minEle) {
            stack.push(x);
        } else {
            stack.push(2L * x - minEle);
            minEle = x;
        }
    }

    public void pop() {
        if (stack.isEmpty()) return;
        long y = stack.pop();
        if (y < minEle) {
            minEle = 2L * minEle - y; // Recover previous min
        }
    }

    public int top() {
        long y = stack.peek();
        if (y < minEle) {
            return minEle.intValue();
        }
        return (int)y;
    }

    public int getMin() {
        return minEle.intValue();
    }
}
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_ele = None

    def push(self, val: int) -> None:
        if not self.stack:
            self.min_ele = val
            self.stack.append(val)
        elif val >= self.min_ele:
            self.stack.append(val)
        else:
            # New min! Store 2*val - min_ele
            self.stack.append(2 * val - self.min_ele)
            self.min_ele = val

    def pop(self) -> None:
        if not self.stack:
            return
        y = self.stack.pop()
        if y < self.min_ele:
            # Recover previous min
            self.min_ele = 2 * self.min_ele - y

    def top(self) -> int:
        y = self.stack[-1]
        return self.min_ele if y < self.min_ele else y

    def getMin(self) -> int:
        return self.min_ele
