Intuition: If current sum $s$ plus the candidate weight $w_k$ exceeds target $M$, kill the node immediately. Because all weights are positive, going deeper will only increase the sum further!

✂️ Bounding Function 2: Underweight Check Right Branch (xₖ = 0)
s + r ≥ M   (and s + wₖ₊₁ ≤ M)

Intuition: If current sum $s$ plus all remaining available weights $r$ is strictly less than target $M$, there is not enough weight in existence to reach $M$. Kill the node immediately!

Phase 1: Greedily Include First 3 Weights {5, 10, 12} s = 27, r = 46

• Root: $(s=0, r=73)$.

• Include w₁ = 5: $s = 0+5=5$, $r = 73-5=68$. ($5 \le 30$ ✅)

• Include w₂ = 10: $s = 5+10=15$, $r = 68-10=58$. ($15 \le 30$ ✅)

• Include w₃ = 12: $s = 15+12=27$, $r = 58-12=46$. ($27 \le 30$ ✅)

Phase 2: Try Including w₄ = 13 ➜ Exceeds 30 ➜ KILLED ✕ 40 > 30 (KILLED)

Bounding Function 1 Triggers: $s + w_4 = 27 + 13 = \mathbf{40} > 30$.

This branch is killed immediately! We do not explore any children of this node.

Next: Try excluding $w_4$ ($x_4 = 0$) ➜ $s = 27, r = 33$. Then trying $w_5 = 15$ gives $27+15=42 > 30$ (Killed ✕). Trying $w_6 = 18$ gives $27+18=45 > 30$ (Killed ✕). Remaining weights exhausted $\implies$ BACKTRACK to w₃!

Phase 3: Backtrack to w₃ = 0, w₄ = 0, Include w₅ = 15 ➜ SOLUTION 1! 🏆 Sum = 30 (EXACT)

• Backtrack up to $(s=15, r=58)$ and exclude w₃ = 12 ($x_3 = 0$) ➜ $(s=15, r=46)$.

• Try $x_4 = 1$ ($w_4 = 13$) ➜ $15+13=28$, but subsequent weights $15, 18$ both exceed 30 $\implies$ backtrack!

• Try exclude w₄ = 13 ($x_4 = 0$) ➜ $(s=15, r=33)$.

• Now include w₅ = 15 ($x_5 = 1$):

s = 15 + 15 = 30 == Target M! 🎯

🎉 Vector: X = (1, 1, 0, 0, 1, 0) ➜ Subset {w₁, w₂, w₅} = {5, 10, 15} = 30!

4. Recursive Algorithm & Complexity

Abdul Bari canonical SumOfSub(s, k, r) procedure & asymptotic bounds

Canonical SumOfSub(s, k, r) Backtracking Algorithm (Weights Sorted in Ascending Order) 
function SumOfSub(s, k, r):
    // s = current sum of included weights
    // k = current element index being decided
    // r = sum of all remaining elements from k to n

    // 1. GENERATE LEFT CHILD: Include w[k] (x[k] = 1)
    x[k] = 1

    if (s + w[k] == M):
        PrintSolution(x, k)  // Target M reached! 🎯
    else if (s + w[k] + w[k+1] <= M):
        SumOfSub(s + w[k], k + 1, r - w[k])  // Explore deeper

    // 2. GENERATE RIGHT CHILD: Exclude w[k] (x[k] = 0)
    if (s + r - w[k] >= M) and (s + w[k+1] <= M):
        x[k] = 0
        SumOfSub(s, k + 1, r - w[k])  // Explore without w[k]
