What is Ternary Search?

Similar to binary search, **Ternary Search** is a divide-and-conquer algorithm for sorted arrays. However, instead of dividing the search space in half, it divides it into **three equal parts** using two calculated midpoint indices.

🔑 Double Midpoint Formulas

Using boundary indices `low` and `high`, we compute two midpoints:

  • mid1 = low + (high - low) / 3
  • mid2 = high - (high - low) / 3

By checking values at `mid1` and `mid2`, we determine which of the three segments contains the key:

  • If `key == arr[mid1]`: Found at `mid1`!
  • If `key == arr[mid2]`: Found at `mid2`!
  • If `key < arr[mid1]`: Search left segment `[low, mid1 - 1]`.
  • If `key > arr[mid2]`: Search right segment `[mid2 + 1, high]`.
  • Otherwise: Search middle segment `[mid1 + 1, mid2 - 1]`.

Continuous Functions Maxima

Beyond looking up elements, Ternary Search is widely used in mathematics to find the maximum or minimum of a **unimodal function** (a function that rises to a peak and then declines) over a continuous interval.

Step-by-Step Trisection Trace

Page 2

Let us trace searching for target **25** in the sorted list: `[5, 10, 15, 20, 25, 30, 35, 40, 45]`.

Step 1: Initial Bounds (low=0, high=8)

• Midpoint 1: `mid1 = 0 + (8 - 0) / 3 = 2` (val = 15).
• Midpoint 2: `mid2 = 8 - (8 - 0) / 3 = 6` (val = 35).
• Comparison: Since `15 < 25 < 35`, target lies in the middle segment. Shrink range to `[3, 5]`.

Step 2: Second Segment (low=3, high=5)

• Midpoint 1: `mid1 = 3 + (5 - 3) / 3 = 3` (val = 20).
• Midpoint 2: `mid2 = 5 - (5 - 3) / 3 = 5` (val = 30).
• Comparison: Since `20 < 25 < 30`, target is in the middle segment: `[4, 4]`.

Step 3: Found (low=4, high=4)

• Midpoint 1: `mid1 = 4`. Midpoint 2: `mid2 = 4` (val = 25).
• Comparison: `arr[mid1] == 25`. Found at index 4!

Ternary Search Complexity Analysis

Page 3

Performance Boundaries

Case Scenario Time Complexity
Best Case The key is found at `mid1` or `mid2` on the first iteration. O(1)
Average Case Target is located after trisection loops. Takes about 2/3 range cuts. O(log3 N)
Worst Case Target is not present or situated at the deepest recursive level. O(log3 N)

📝 Ternary vs. Binary Performance:

Although ternary search has a smaller logarithmic base (log3 vs log2), it performs **four comparisons** per step in the worst case (compared to two in binary search). Consequently, binary search is faster in practice for standard array lookups.
