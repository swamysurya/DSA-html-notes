Doubly Linked Lists & Linked Memory

Page 1

What is std::list?

In C++, std::list is a sequence container implemented as a **Doubly Linked List**. Unlike vectors, list elements are stored in non-contiguous blocks of memory (scattered throughout the heap). Nodes are connected through explicit memory pointers.

🔑 Node Structure & Pointers

Each element in a doubly linked list is wrapped in a **Node** structure containing:

  • Data: The actual stored value.
  • Next Pointer: A pointer to the next node in the list (or NIL if it is the tail).
  • Prev Pointer: A pointer to the previous node in the list (or NIL if it is the head).

No Random Access

Because memory is non-contiguous, we cannot perform address arithmetic to find an element in O(1) time. Finding element `[i]` requires starting at the head (or tail) and sequentially traversing pointer links, taking **O(N)** time.

However, if we already hold a pointer to a node, insertion or deletion takes strictly **O(1)** time since it only requires swapping four pointers.

Conceptual Node Connections: Bidirectional pointer lines link nodes dynamically.

Step-by-Step Middle Insertion

Page 2

Let us trace inserting node **15** in the middle of a doubly linked list containing elements **10** and **20** (linked as 10 ↔ 20).

Step 1: Current State

Node 10 points forward to 20. Node 20 points backward to 10.

Step 2: Allocate Node 15

• Allocate node 15 in memory.
• Point 15's `prev` pointer to 10, and 15's `next` pointer to 20. Nodes 10 and 20 are not modified yet.

Step 3: Redirect Pointers (Insertion complete)

• Redirect 10's `next` pointer to 15.
• Redirect 20's `prev` pointer to 15.
• The list is now linked as: 10 ↔ 15 ↔ 20.

List Methods & Complexity Analysis

Primary std::list Operations

Method Description Average Time Worst-Case Time
push_front(val) / push_back(val) Inserts at front/end. Direct pointer manipulation. O(1) O(1)
pop_front() / pop_back() Removes from front/end and deletes node block. O(1) O(1)
insert(iterator, val) Inserts value *before* iterator position. O(1) O(1)
erase(iterator) Removes element at iterator position. O(1) O(1)
find(val) Traverses list node by node to search value. O(N) O(N)

📝 Advantages & Drawbacks:

  • Efficient Insert/Erase: No shifting of elements is ever required, unlike vectors. This avoids large memory reallocations.
  • Iterators Stability: Adding or removing items does not invalidate pointers to other nodes.
  • Poor Cache Locality: Since nodes are scattered in memory, traversing lists results in frequent CPU cache misses, making them slower in practice than vectors for iteration.
  • Space Overhead: Each node consumes extra memory for two pointer variables (`prev` and `next`), typically 16 bytes overhead per element.
