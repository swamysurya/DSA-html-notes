What is Quick Sort?

**Quick Sort** is a highly efficient, comparison-based, in-place sorting algorithm. It utilizes a **divide-and-conquer** approach by selecting a **pivot element** and partitioning the rest of the array into two sub-arrays: elements smaller than the pivot and elements larger than the pivot.

🔑 Lomuto Partition Scheme

One of the most common partitioning schemes, **Lomuto Partitioning**, operates as follows:

  • Pivot Selection: Choose the last element of the range (`arr[high]`) as the pivot.
  • i Boundary Pointer: Tracks the dividing line between elements smaller than the pivot and elements larger than it.
  • j Scanning Pointer: Scans from `low` to `high - 1`. If `arr[j] <= pivot`, increment `i` and swap `arr[i]` with `arr[j]`.
  • Final Pivot Swap: Once scanning completes, swap the pivot element with `arr[i + 1]`. The pivot is now in its correct sorted index.

Unstable In-place sorting

Because Quick Sort performs distant element swapping across the pivot boundary, it is **unstable** (relative duplicate order might swap). However, it requires **O(1) constant auxiliary space** (excluding recursion stack frames), making it highly cache-friendly.

Step-by-Step Partition Trace

Page 2

Let us trace Lomuto partitioning on: `[4, 2, 5, 1, 3]`, with pivot = **3** (index 4).

Step 1: Check elements smaller than pivot

• Scan index 0 (val 4 > 3). No swap.
• Scan index 1 (val 2 <= 3). Swap with index 0 -> `[2, 4, 5, 1, 3]`. i boundary increments to 0.

Step 2: Scan remaining and swap pivot

• Scan index 3 (val 1 <= 3). Swap with index 1 -> `[2, 1, 5, 4, 3]`. i boundary is 1.
• Swap pivot 3 with index 2 (i+1) -> `[2, 1, 3, 4, 5]`. Pivot 3 is locked in place.

Quick Sort Complexity Analysis

Page 3

Asymptotic Runtime Bounds

Case Scenario Time Complexity
Best Case Pivot always splits subarrays perfectly in half. O(N log N)
Average Case Randomized pivots yield balanced sub-partitions on average. O(N log N)
Worst Case Pivots chosen are extreme elements (e.g. sorted arrays using basic boundary pivot), splitting range as N-1 and 0. O(N^2)

🔑 Avoiding the O(N^2) Worst Case:

We can practically eliminate the O(N^2) worst case by implementing **Randomized Quick Sort**, where the pivot index is chosen at random and swapped with the last element before partitioning begins.
