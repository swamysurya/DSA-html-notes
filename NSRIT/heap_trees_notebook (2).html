Heap Tree (Priority Queues) :-

Heap tree is a complete binary tree data structure that satisfies the heap property for every node, the value of its children is greater than or equal to its own value (Min Heap) or less than or equal to its own value (Max Heap). Heaps are usually used to implement priority queues, where the smallest or largest element is always at the root of the tree.

Example Array:

25, 67, 22, 91, 62, 52, 63, 92, 90

There are two main types of heaps:

  1. MAX heap (maximum heap)
  2. MIN heap (minimum heap)

1. MAX heap: The root node contains maximum value, and the value decreases as you move down the tree.

2. MIN heap: The root node contains minimum value, and the value increases as you move down the tree.

Heap Operations

Heap-Tree Operations:-

  1. Insertion
  2. Deletion

1. Insertion:

Add a new element to the heap while maintaining the heap property.

(i) Min heap insertion

(ii) Max heap insertion

Algorithm for MAX heap insertion:

  1. Step 1: Create a new node at the end of heap tree.
  2. Step 2: Assign new value to the node.
  3. Step 3: Compare the value of this child node with its parent.
  4. Step 4: If value of parent is less than child, then swap them.
  5. Step 5: Repeat Step 3 and 4 until heap property holds.

Example 1 (Max Heap):

Initial Array: 24, 26, 31, 25, 14, 18, 29, 35, 27

Action 1: Insert 100

Action 2: Insert 44

Algorithm for MIN heap insertion:

  1. Step 1: Create a new node at the end of heap tree.
  2. Step 2: Assign new value to the node.
  3. Step 3: Compare the value of this child node with its parent.
  4. Step 4: If value of parent is more than child, then swap them.
  5. Step 5: Repeat Step 3 and 4 until heap property holds.

Example 2 (Min Heap):

Initial Array: 100, 10, 50, 49, 0, 64, 99, -3, 14, 33, 61

Action 1: Insert -1

Action 2: Insert 1000

2. Deletion:

Remove the Minimum or Maximum element from the heap tree and return it.

Algorithm for MAX heap deletion:

  1. Step 1: Remove root node (the maximum element).
  2. Step 2: Move the last element of the last level to the root index.
  3. Step 3: Compare the value of this new root node with its children.
  4. Step 4: If value of node is less than a child then swap it with the larger child.
  5. Step 5: Repeat Step 3 and 4 until heap property holds (Bubble-down).

Example: 3 Consecutive Node Deletions (Max Heap)

Initial Max Heap: 99, 72, 55, 68, 14, 34, 42, 29

Action 1: Delete Root Node (99)

Action 2: Delete Next Root (72)

Action 3: Delete Next Root (68)

Algorithm for MIN heap deletion:

  1. Step 1: Remove root node (the minimum element).
  2. Step 2: Move the last element of the last level to the root index.
  3. Step 3: Compare the value of this new root node with its children.
  4. Step 4: If value of node is more than a child then swap it with the smaller child.
  5. Step 5: Repeat Step 3 and 4 until heap property holds (Bubble-down).

Example: 3 Consecutive Node Deletions (Min Heap)

Action 2: Delete Next Root (-2)

Applications

Applications of heap tree :-

  1. Heaps are commonly used to implement priority queues, where elements are retrieved based on their priority (Max or Min value).
  2. Heap tree are used in graph algorithms like Prims algorithm and Dijkstra's algorithm for finding the shortest path and minimum spanning tree.
  3. Heapsort is a sorting algorithm that uses a heap sort an array in ascending or descending order.
