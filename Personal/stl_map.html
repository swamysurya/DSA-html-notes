What is std::map?

In C++, std::map is an associative container that stores elements formed by a combination of a **unique key** and a **mapped value**. The keys are used to sort and uniquely identify the elements, while the values store the actual data.

🔑 Key-Value Sorting & Red-Black Tree representation

Under the hood, `std::map` is structured as a **Red-Black Tree** of key-value nodes (using std::pair<const Key, Value>):

  1. Key Comparison: When inserting `{Key, Value}`, the tree uses the Key to search for its position (keys must be unique; inserting a duplicate updates or rejects depending on configuration).
  2. Red-Black balancing: Rotations and recoloring are applied identical to standard RBTs to keep heights logarithmic: Height ≤ 2 × log2(N).
  3. In-order Iteration: Because it is a BST, iterating from `begin()` to `end()` returns elements sorted by key.

Map vs. Set

While `std::set` only stores keys (acting as an ordered collection of values), `std::map` maps each key to a separate data value. However, the balancing, heights, and logarithmic O(log N) lookup rules remain identical.

Conceptual Key-Value RBT Node: Each node holds Key:Value (e.g. 20:A).

Step-by-Step Pair Insertion

Page 2

Let us trace inserting the key-value pairs {10: "A"}, {20: "B"}, {30: "C"} into an empty map.

Step 1: Insert {10: "A"}

Key 10 is root, recolored Black.

Step 2: Insert {20: "B"}

Key 20 is greater than 10. Placed as right child (Red).

Step 3: Insert {30: "C"} (Violation!)

Key 30 is placed as right child of 20 (Red). Consecutive Red nodes violation occurs at keys 20 and 30.

Step 4: Rotate & Recolor

Left rotation at key 10. Key 20 becomes Black parent, key 10 and 30 recolor Red.

Map Methods & Complexity Analysis

Page 3

Primary std::map Operations

Method Description Average Time Worst-Case Time
insert({key, val}) Inserts the pair into the tree. Balanced sorted order. O(log N) O(log N)
erase(key) Removes the pair corresponding to the key. Rebalances tree. O(log N) O(log N)
find(key) Searches by key. Returns pair iterator if found, or `end()`. O(log N) O(log N)
operator[key] Accesses value of key. If key doesn't exist, inserts key. O(log N) O(log N)

📝 Key Complexity Facts:

  • Guaranteed logarithmic performance: Finding, inserting, or removing values is guaranteed to take logarithmic time, even in worst-case insertions (unlike unordered_map, which can suffer O(N) lookup).
  • Map iteration sorted order: Iterating a map returns key-value pairs sorted by key.
