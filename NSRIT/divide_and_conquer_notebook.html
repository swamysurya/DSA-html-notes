Divide & Conquer Method & AVL Trees

Page 1

General Method Concept:

Divide and Conquer is a fundamental algorithm design paradigm. It works by:

  • Divide: The main problem is broken down into smaller, similar sub-problems.
  • Conquer: The sub-problems are solved recursively. If they are small enough, they are solved directly (base case).
  • Combine: The solutions of all sub-problems are merged back together to formulate the final answer.

Algorithm Structure:

DAC(p) {
    if (small(p)) {
        return S(p); // Solve directly
    } else {
        divide p into p1, p2, ..., pn
        Apply DAC(p1), DAC(p2), ...
        return Combine(DAC(p1), DAC(p2), ...)
    }
}

Merge Sort Sort & Division Tree

Page 2

Merge sort is a recursive algorithm that repeatedly divides a list in half until individual elements are isolated, then merges them back in sorted order.

MergeSort Algorithm:

Algorithm MergeSort(l, h) {
    if (l < h) {
        mid = (l + h) / 2;
        MergeSort(l, mid);
        MergeSort(mid + 1, h);
        Merge(l, mid, h);
    }
}

Merge Algorithm:

Algorithm Merge(l, mid, h) {
    i = l; j = mid + 1; k = l;
    while (i <= mid && j <= h) {
        if (A[i] <= A[j]) {
            B[k++] = A[i++];
        } else {
            B[k++] = A[j++];
        }
    }
    for (; i <= mid; i++) B[k++] = A[i];
    for (; j <= h; j++) B[k++] = A[j];
    for (i = l; i <= h; i++) A[i] = B[i];
}

Phase 2: Bottom-Up Merging (Combine)

Adjacent sorted sub-arrays are merged back together in ascending sorted order.

Step 2.4: Final Merge

Merge both sorted halves [13, 25, 27, 29, 36] and [20, 42, 54, 98] to get the final sorted array.

Quick Sort & Partitioning Simulator

Page 3

Quick Sort operates by selecting a pivot element and partitioning the array so that elements smaller than the pivot go to the left, and elements larger go to the right.

Quick Sort Algorithm:

QuickSort(A, i, j) {
    if (i < j) {
        p = Partition(A, i, j);
        QuickSort(A, i, p - 1);
        QuickSort(A, p + 1, j);
    }
}

Partition Logic:

Partition(A, l, h) {
    pivot = A[l];
    i = l; j = h;
    while (i < j) {
        while (A[i] <= pivot && i < h) i++;
        while (A[j] > pivot) j--;
        if (i < j) swap(A[i], A[j]);
    }
    swap(A[l], A[j]);
    return j;
}

How Partition Positions the Pivot:

Partitioning works by selecting a pivot element and rearranging the other elements so that all values smaller than the pivot go to its left, and all values larger go to its right. Click the step button below to see how pivot 50 positions itself in its final sorted location.

Pivot Placement Simulation (Pivot: 50)
Initialized pointers: i = 0, j = 6. Pivot = 50.
💡 Why does this work? (Key Intuition)
  • Pointers i and j partition the elements: everything left of j gets swapped to be ≤ pivot, and everything right of i gets swapped to be > pivot.
  • When pointers cross (i ≥ j), index j marks the boundary of the left group. Since A[j] ≤ pivot, swapping the pivot with A[j] places the pivot exactly on this boundary.
  • After the swap, the pivot at index j has only smaller elements on its left and larger elements on its right. Thus, the pivot reaches its exact final sorted position.

Strassen's Matrix Multiplication

Page 4

Standard matrix multiplication requires $O(n^3)$ operations. Strassen's algorithm uses divide-and-conquer block partitions to reduce multiplications from 8 to 7, resulting in a time complexity of $O(n^{\log_2 7}) \approx O(n^{2.81})$.

Strassen's Formulas:

  • $P = (A_{11} + A_{22})(B_{11} + B_{22})$
  • $Q = (A_{21} + A_{22})B_{11}$
  • $R = A_{11}(B_{12} - B_{22})$
  • $S = A_{22}(B_{21} - B_{11})$
  • $T = (A_{11} + A_{12})B_{22}$
  • $U = (A_{21} - A_{11})(B_{11} + B_{12})$
  • $V = (A_{12} - A_{22})(B_{21} + B_{22})$

Formulating Results:

  • $C_{11} = P + S - T + V$
  • $C_{12} = R + T$
  • $C_{21} = Q + S$
  • $C_{22} = P + R - Q + U$

    Convex Hull - Divide & Conquer

    Page 5

    The Convex Hull of a set of 2D points is the smallest convex polygon enclosing all points. The divide and conquer approach splits the points, recursively computes the hulls of left and right halves, and merges them using **upper and lower tangents**.

    tangent Merging & Base Cases:

    • Tangent Finding: Tangents are segments connecting left hull A and right hull B without intersecting either interior.
    • Brute Force Base Case: Small sets of points ($\le 5$) are solved directly using brute-force algorithms to prevent infinite tangent-matching loops when merging small pairs.
