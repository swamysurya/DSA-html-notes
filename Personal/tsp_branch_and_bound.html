§1.1 The Formal Problem Statement

Let G = (V, E) be a directed, weighted graph with |V| = n vertices. We are given a cost matrix C[n][n] where C[i][j] is the cost of travelling from city i to city j (C[i][i] = ∞).

1. Complete Tour:

The salesperson must visit every single vertex exactly once (Hamiltonian Cycle).

2. Return to Start:

Starting conventionally from vertex 1, the tour must return back to vertex 1 at the end.

3. Minimize Total Cost:

The objective is to find the permutation that minimizes the sum of edge costs along the tour.

💡 Key Insights from the 4-Vertex Example:

  • Fixed Origin: Without loss of generality, we fix the starting vertex as vertex 1. This avoids counting identical cycles with rotated starting points.
  • Tour Decisions: At vertex 1, the salesperson has (n - 1) = 3 choices: visit vertex 2, 3, or 4.
  • Brute Force Flaw: Generating all (n - 1)! = 3! = 6 tours (or (n-1)! in general) explodes factorially.
  • Branch and Bound Goal: Compute a mathematical lower bound at every intermediate step. If a partial path already costs more than a known complete tour, kill it instantly without exploring its children!

2. Reduced Cost Matrix Mechanics & Explicit "WHY" Rationale

§2.1 What is a "Reduced Cost Matrix"?

📌 Formal Definition:

A cost matrix is said to be Reduced if and only if:

  1. Every Row contains at least one zero (0), or all its entries are ∞.
  2. Every Column contains at least one zero (0), or all its entries are ∞.

✈️ The Real-Life Analogy: Mandatory Airport Departure & Landing Taxes

Imagine 5 cities. Every time a flight takes off from City 1, the airline MUST pay at least $10 departure tax, regardless of destination. Every time a flight lands in City 3, they MUST pay at least $3 arrival tax.

• Row Minimum = The minimum unavoidable cost required to LEAVE that city.
• Column Minimum = The minimum unavoidable cost required to ENTER that city.

Because a complete tour must leave every city exactly once and enter every city exactly once, summing all row and column reductions guarantees the absolute minimum baseline cost any valid tour can ever achieve!

§2.3 Branching Transition Rules: Why Row i = ∞, Col j = ∞, and M[j][1] = ∞?

Suppose the salesman is currently at vertex i and chooses to travel to vertex j (taking edge i → j). We must transform the parent matrix Mparent into the child matrix Mchild following 4 strict mathematical rules:

1️⃣ Rule 1: Set Row i = ∞

WHY? In a Hamiltonian tour, the salesman can depart from city i exactly once! Since edge i → j has been selected, city i can never have any other outgoing edge. Setting the entire row to ∞ permanently disables all other departures from city i.

2️⃣ Rule 2: Set Column j = ∞

WHY? The salesman can enter city j exactly once! Since city j has now been entered via edge i → j, no other city can ever lead into city j again. Setting the entire column to ∞ eliminates all duplicate incoming arrivals.

3️⃣ Rule 3: Set M[j][1] = ∞

WHY? (Preventing Premature Sub-Cycles) The salesman must visit ALL cities before returning to the start city 1. If edge j → 1 were permitted prematurely, the salesman would loop back to city 1 and terminate the tour before visiting the remaining cities!

4️⃣ Rule 4: The Child Cost Formula
ĉ(child) = ĉ(parent) + Mparent[i][j] + r'

Where Mparent[i][j] is the edge cost in the parent's reduced matrix, and r' is the additional reduction required to re-reduce the newly formed matrix.

§4.1 High-Level LC-BB Algorithm Pseudocode

// Abdul Bari Reduced Matrix LC-BB for TSP
Algorithm TSP_LCBB(CostMatrix C, n):
1. Reduce C by subtracting row and col minima; initialCost = r_row + r_col.
2. Create root node: path = [1], reducedMatrix = C, cost = initialCost, level = 0.
3. Initialize Min-Heap Priority Queue PQ, push root.
4. while PQ is not empty:
a. curr = PQ.pop()
b. if curr.level == n - 1:
Complete tour to remaining city & start city 1.
return curr.cost and curr.path. // Optimal guaranteed!
c. for each unvisited city j:
i. child.matrix = copy(curr.reducedMatrix)
ii. child.matrix[curr.city][:] = ∞; child.matrix[:][j] = ∞; child.matrix[j][1] = ∞
iii. r' = reduce(child.matrix)
iv. child.cost = curr.cost + curr.reducedMatrix[curr.city][j] + r'
v. PQ.push(child)

// =========================================================================
// Abdul Bari - Traveling Salesperson Problem (TSP) using Branch and Bound
// Technique: Least-Cost Branch & Bound (LC-BB) via Reduced Cost Matrix
// =========================================================================

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

const int INF = 1e9;

// State Space Tree Node
struct Node {
    vector<int> path;              // Tour path visited so far
    vector<vector<int>> reducedMatrix; // Reduced cost matrix for this node
    int cost;                     // Lower bound cost (c_hat)
    int vertex;                   // Current city index (0-indexed)
    int level;                    // Number of cities visited
};

// Comparator for Min-Heap Priority Queue (Least Cost First)
struct CompareNode {
    bool operator()(const Node& a, const Node& b) const {
        return a.cost > b.cost;
    }
};

// Function to reduce the cost matrix and return the total reduction amount
int reduceMatrix(vector<vector<int>>& matrix, int n) {
    int reductionCost = 0;

    // 1. Row Reduction
    for (int i = 0; i < n; ++i) {
        int rowMin = INF;
        for (int j = 0; j < n; ++j) {
            if (matrix[i][j] < rowMin) rowMin = matrix[i][j];
        }
        if (rowMin != INF && rowMin > 0) {
            reductionCost += rowMin;
            for (int j = 0; j < n; ++j) {
                if (matrix[i][j] != INF) matrix[i][j] -= rowMin;
            }
        }
    }

    // 2. Column Reduction
    for (int j = 0; j < n; ++j) {
        int colMin = INF;
        for (int i = 0; i < n; ++i) {
            if (matrix[i][j] < colMin) colMin = matrix[i][j];
        }
        if (colMin != INF && colMin > 0) {
            reductionCost += colMin;
            for (int i = 0; i < n; ++i) {
                if (matrix[i][j] != INF) matrix[i][j] -= colMin;
            }
        }
    }

    return reductionCost;
}

// Solves the TSP using Least-Cost Branch and Bound
int solveTSP(vector<vector<int>> adj, int n, vector<int>& bestTour) {
    priority_queue<Node, vector<Node>, CompareNode> pq;

    // Initialize Root Node (City 0 corresponds to City 1)
    Node root;
    root.path.push_back(0);
    root.reducedMatrix = adj;
    root.vertex = 0;
    root.level = 1;
    root.cost = reduceMatrix(root.reducedMatrix, n);

    pq.push(root);

    while (!pq.empty()) {
        Node curr = pq.top();
        pq.pop();

        int u = curr.vertex;

        // If all cities visited, return to starting city 0
        if (curr.level == n) {
            curr.path.push_back(0);
            bestTour = curr.path;
            return curr.cost;
        }

        // Explore unvisited destinations v
        for (int v = 0; v < n; ++v) {
            if (find(curr.path.begin(), curr.path.end(), v) == curr.path.end() && curr.reducedMatrix[u][v] != INF) {
                Node child;
                child.path = curr.path;
                child.path.push_back(v);
                child.reducedMatrix = curr.reducedMatrix;

                // Apply Rules: row u = INF, col v = INF, child[v][0] = INF
                for (int k = 0; k < n; ++k) {
                    child.reducedMatrix[u][k] = INF;
                    child.reducedMatrix[k][v] = INF;
                }
                child.reducedMatrix[v][0] = INF;

                int r_prime = reduceMatrix(child.reducedMatrix, n);
                child.cost = curr.cost + curr.reducedMatrix[u][v] + r_prime;
                child.vertex = v;
                child.level = curr.level + 1;

                pq.push(child);
            }
        }
    }
    return INF;
}

int main() {
    int n = 5;
    vector<vector<int>> costMatrix = {
        { INF, 20,  30,  10,  11 },
        { 15,  INF, 16,  4,   2  },
        { 3,   5,   INF, 2,   4  },
        { 19,  6,   18,  INF, 3  },
        { 16,  4,   7,   16,  INF }
    };

    vector<int> bestTour;
    int minCost = solveTSP(costMatrix, n, bestTour);

    cout << "=== Abdul Bari TSP Solution (Branch and Bound) ===\n";
    cout << "Minimum Tour Cost: " << minCost << "\n";
    cout << "Optimal Tour Path: ";
    for (size_t i = 0; i < bestTour.size(); ++i) {
        cout << (bestTour[i] + 1) << (i + 1 == bestTour.size() ? "" : " -> ");
    }
    cout << "\n";

    return 0;
}

§4.3 Time and Space Complexity Analysis

⏳ Time Complexity
• Matrix Reduction per node: O(n2)
• Worst-Case States Generated: O(n!) or O(2n)
⇒ Worst-Case Time: O(n2 · 2n)
⇒ LC-BB Practical: Explores only 11 nodes out of 120!

Without Branch and Bound, an exhaustive permutation search tests (n-1)! = 4! = 24 complete tours and hundreds of subtree evaluations. Reduced-matrix LC-BB converges in just 11 total nodes!

💾 Space Complexity
• Cost Matrix stored per live node: O(n2)
• Min-Heap size in worst case: O(2n)
⇒ Auxiliary Space: O(n2 · 2n)
• Dynamic Programming contrast: O(n · 2n)

Branch and Bound stores the reduced matrix inside each active node in the Min-Heap. Although memory usage is higher than backtracking's O(n) stack, it avoids redundant recalculations.
